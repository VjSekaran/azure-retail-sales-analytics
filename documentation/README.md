# Project Documentation

This folder contains detailed documentation and learning material for the Azure Retail Sales Analytics project.

## Contents

The documentation explains the project from end to end, including:

- Business problem
- Project architecture
- Azure services
- Azure Data Factory
- ADLS Gen2
- Azure Databricks
- Apache Spark
- PySpark
- Spark SQL
- Medallion Architecture
- Bronze, Silver and Gold layers
- Delta Lake
- Data quality
- Star Schema
- Power BI semantic model
- DAX measures
- Dashboard design
- Data validation
- Interview preparation
- Project learning roadmap

## Project Approach

The project follows this overall workflow:

Source Data
↓
Azure Data Factory
↓
ADLS Gen2
↓
Databricks Bronze
↓
Databricks Silver
↓
Databricks Gold
↓
Star Schema
↓
Power BI
↓
Business Insights

## Study Guide

The detailed study guide provides explanations of what was done at each stage, why the technology or approach was used, and what benefits it provides.

## Purpose

The documentation is intended to make the project reproducible and understandable for:

- Data Analysts
- Data Engineers
- BI Developers
- Recruiters
- Interviewers
- Learners studying Azure analytics
